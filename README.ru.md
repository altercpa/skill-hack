## Что это

**Хак** — расширение для [AlterCPA](https://www.altercpa.pro): Lite, Pro или Core. Он добавляет страницы
панели управления, модули, библиотеки, API-приложения, таблицы базы данных, задачи cron, а также
рекламные и логистические коннекторы. Код самой платформы недоступен для чтения, поэтому расширять её
можно только через документированные интерфейсы.

Это **скилл** для [Claude](https://claude.com), в котором эти интерфейсы собраны — руководство по
разработке хаков, страница за страницей. С ним Claude строит хак так, как ожидает платформа, а не
придумывает API.

## Три правила, которые он навязывает

1. **Стиль кода обязателен** — табуляция, скобки, имена, шапка файла: новый код неотличим от кода платформы.
2. **Настройки — один массив, а не схема** — страница настроек с двенадцатью полями это двенадцать
   ключей одного массива, а не двенадцать колонок.
3. **Имя хака — идентификатор** — только строчные латинские буквы и цифры, потому что оно становится
   именами классов, функций и таблиц.

## Что покрывает

| Область | Страницы |
|---|---|
| **Основы** | что такое хак, стартовый файл, главный класс и его конфигурация |
| **Объект платформы** | события, конфигурация, кэш, сессии, пользователи и маршрутизация, текстовые хелперы, сборка страниц и формы, медиа, почта, глобальные функции |
| **Разработка** | контроллеры, библиотеки, языковые файлы, шаблоны и паттерны вёрстки, страница настроек, API-приложения, задачи cron, база данных |
| **Коннекторы** | рекламные сети, службы доставки, распространение обновлений |
| **Стиль** | руководство по стилю кода |

## Установка

### Claude Code

Скачайте [`altercpa-hacks-skill.zip`](https://github.com/altercpa/skill-hack/releases/latest/download/altercpa-hacks-skill.zip)
и распакуйте в папку скиллов:

```sh
unzip altercpa-hacks-skill.zip -d ~/.claude/skills/        # для всех проектов
unzip altercpa-hacks-skill.zip -d .claude/skills/          # только для этого проекта
```

В Windows распакуйте в `%USERPROFILE%\.claude\skills\`.

Предпочитаете git? Клонируйте прямо в папку скиллов — обновление сводится к `git pull`:

```sh
git clone https://github.com/altercpa/skill-hack.git ~/.claude/skills/altercpa-hacks
```

### Claude.ai и Claude Desktop

В настройках Claude добавьте собственный скилл и загрузите тот же zip.

## Как пользоваться

Вызывать ничего не нужно — Claude подключает скилл сам, когда запрос касается хаков AlterCPA. Например:

- *Создай новый хак AlterCPA, который добавляет страницу в панель управления с формой настроек.*
- *Добавь в мой хак задачу cron и API-приложение.*
- *Проверь код моего хака на соответствие стилю платформы.*

## Обновления

Релизы помечаются тегами `vГГГГ.ММ.ДД`. Подпишитесь на репозиторий (*Watch → Custom → Releases*), чтобы
получать уведомления, затем скачайте новый zip — или выполните `git pull`, если клонировали.
